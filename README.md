# FVCKPREFLOP

Быстрый просмотрщик префлоп-чартов для Spin&Go / Expresso Nitro. Печатаешь пару
букв сценария в поиске → Enter → чарт на весь экран. Пробел листает
доп.варианты (vs shove / vs 3bet 3x), если они есть для этой связки
сценарий+стек.

## Запуск

```bash
npm install
npm run dev
```

## Как добавить/заменить реальные чарты

1. Картинки лежат в `public/charts/`. Сейчас там сгенерированы
   SVG-заглушки (`npm run gen-placeholders` пересоздаёт их из конфига).
2. Просто положи свои реальные картинки (PNG/JPG/SVG) в `public/charts/`
   с теми же именами файлов, что указаны в `src/data/charts.json` — код
   менять не нужно.
3. Чтобы добавить новый сценарий, стек или доп.вариант (vsshove,
   vs3bet3x, ...) — допиши объект в `src/data/charts.json`:

```json
{
  "id": "CO_open",
  "label": "CO open (folded to)",
  "stacks": [
    { "bb": 15, "variants": { "open": "CO_open_15bb.png", "vsshove": "CO_open_15bb_vsshove.png" } }
  ]
}
```

и положи соответствующий файл картинки рядом в `public/charts/`. Список
сценариев и стеков в приложении обновится автоматически, хардкодить
позиции/стеки в коде не нужно.

## Управление

- Печатай в поиске часть названия сценария (например `sb mr 15`, `btn
  open`, `vsshove`) — список фильтруется на лету.
- `↑ / ↓` — выбрать вариант в списке, `Enter` — открыть чарт.
- В режиме просмотра чарта: `Space` — циклически переключает
  доступные доп.варианты (open → vsshove → vs3bet3x → снова open).
- В режиме просмотра чарта: начни печатать любую букву — мгновенно
  вернёшься в поиск с этой буквой уже введённой, чтобы найти следующий стол.
